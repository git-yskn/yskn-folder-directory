Panduan Penamaan File

Format baku:

TAHUN-BULAN-TANGGAL_Kategori_Deskripsi_vX

Contoh: 2026-11-07_Laporan_Bantuan-Banjir-Jakarta_v1.pdf

  • Gunakan garis bawah (_) tanpa spasi.
  • Awali folder dengan nomor urut.
  • Pisahkan arsip per tahun, misalnya /2026/.
